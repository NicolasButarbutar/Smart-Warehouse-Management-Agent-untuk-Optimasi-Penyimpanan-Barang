# Data

Folder ini disiapkan untuk kebutuhan Milestone 2 (Data Collection & Data Understanding).

- `raw/` — data mentah apa adanya (mis. ekspor denah gudang, daftar SKU, histori transaksi) sebelum diproses. Jangan diedit langsung.
- `processed/` — data yang sudah dibersihkan/diolah dan siap dipakai oleh modul analisis atau model.

Berkas data sebaiknya tidak di-commit dalam jumlah besar ke repositori publik; gunakan `.gitignore` atau Git LFS bila ukurannya besar, dan cukup commit skema/contoh kecil sebagai dokumentasi.
